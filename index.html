Border Styling Showcase

Techniques: Borders for Text

Six distinct methods of applying borders directly to text elements, labels, headlines, and callouts.

01 Text Character Stroke (Hollow Border)
OUTLINE GLOW

Uses -webkit-text-stroke: 1.5px #38ef7d with transparent fill, generating an authentic border directly outlining individual letterforms.

02 Solid Neon Border on Text Pill
✦ MISSION CERTIFIED ✦

Applies border: 2px solid #00f2fe with soft border-radius and inner padding to enclose the text within a luminous boundary.

03 Dashed Cyberpunk Text Frame
TELEMETRY DATA LOCK

Configured with border: 2px dashed #f6d365, creating a technical, high-tech dashboard aesthetic around text labels.

04 Double Border Text Plaque
DEEP SPACE OBSERVATORY

Utilizes border: 4px double #e056fd to render concentric outer and inner stroke lines framing the text title.

05 Asymmetric Left Border Quote
"Somewhere, something incredible is waiting to be known." — Carl Sagan

Implements border-left: 4px solid #4facfe paired with subtle background tinting for editorial text callouts.

06 Shimmering Gradient Border
STELLAR INTERFACE v2.4

Uses a dual-layer linear gradient border with pseudo-element animation, highlighting textual highlights with shimmering colors.

style.css (External Stylesheet) 
/* 1. Background Image with Dark Vignette */
body {
  background-image: 
    linear-gradient(
      rgba(10, 11, 26, 0.78), 
      rgba(10, 11, 26, 0.88)
    ),
    url('images/background.jpg');
  background-size: cover;
  background-position: center;
  background-attachment: fixed;
}

/* 2. Text Colors & Gradient Clipping */
.gradient-text {
  background: linear-gradient(135deg, #00f2fe, #4facfe, #e056fd);
  -webkit-background-clip: text;
  color: transparent;
}

/* 3. Text Border (Character Outline) */
.text-border-stroke {
  color: transparent;
  -webkit-text-stroke: 1.5px #38ef7d;
}

/* 4. Text Border (Pill Badge) */
.text-border-solid {
  border: 2px solid #00f2fe;
  border-radius: 50px;
  padding: 8px 22px;
}
